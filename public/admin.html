💡 初回メール受信時のご注意（FormSubmit使用時）

✉️ メール送信方式・SMTP設定 (Resend / Gmail)
Resend の APIキーを設定すると、FormSubmit の制限を受けずにクラウド（Render等）から100%確実にメールが送信されます。
SMTP直接送信: 無効 (FormSubmit使用)
💡 Resend の始め方（無料・登録後1分で完了）:
1. resend.com 🌐 で無料アカウントを作成
2. 左メニュー「API Keys」→「Create API Key」でキーを発行
3. 発行された re_... を下の「Resend API キー」欄に貼り付けて保存するだけです。
※ Resend管理画面で発行した re_... から始まるAPIキーを入力してください。
※ 独自ドメイン未設定のテスト時は onboarding@resend.dev のままでOKです。
